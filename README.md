# VettedMapLeads

Static GitHub Pages front end for VettedMapLeads.

## Publish on GitHub Pages
1. Keep `index.html` at the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`. Save.
4. Wait for GitHub Pages to publish the site.

The contact form uses Web3Forms. Lead and Business Spotlight checkout links continue to use the existing secure VettedMapLeads backend. Keep the PayPal webhook attached to that backend.
